Claude Agent SDK

Breaking: v2 session API removed

v0.3.142 · May 14

The unstable v2 session helpers (unstable_v2_createSession and friends) are gone. Use query() instead. Also: MCP servers now connect in the background — sessions start immediately with status: "pending" while slow servers warm up.

If any code imports unstable_v2_* the build breaks today. query() covers the same surface and the docs are now stable.
ts// before
const s = await unstable_v2_createSession({ model });

// after
import { query } from "@anthropic-ai/claude-agent-sdk";
const r = await query({ model, prompt });

May 12

Practical ideas — 5 ideas this week

Concrete ways to use this week's changes in your Node / TypeScript service · each tied to a changelog item above
1

Audit every dall-e-* call site before it 404s

Breaking risk

OpenAI removed the DALL·E 2 and DALL·E 3 models on May 12. Any service still calling images.generate({ model: "dall-e-2" }) or "dall-e-3" returns 404 right now.

One-line fix per call site, but you have to find them all. The model usually fails silently — paths exercised rarely won't surface the break until a real user hits them.
bash# find every call site in your codebase
rg 'model:\s*["'\''"](dall-e-[23])["'\''"]' --type ts

# then change model to gpt-image-2 (drop-in replacement)

Grep for unstable_v2_ before the next Agent SDK bump

Breaking risk

Claude Agent SDK v0.3.142 removed the v2 session API. If any tool, worker, or test imports unstable_v2_createSession (or its siblings), the next dependency bump kills the build.

Dependabot tends to propose Agent SDK bumps quietly. Catching this now avoids a red-CI fire-drill later.
bashrg 'unstable_v2_' --type ts
# migrate hits to:
#   import { query } from "@anthropic-ai/claude-agent-sdk"
#   const r = await query({ model, prompt, cwd })
