# AI Tools Weekly

Auto-generated weekly digest of the latest changes to claude-code, the
Claude Agent SDK, Codex, and the OpenAI SDK — plus 5 practical ideas for
SysAid each week.

**Latest digest:** https://matanel-weizman.github.io/AI-Tools-Weekly/

Generated every Monday 08:00 IDT by a remote `/schedule` Claude routine.
See `ROUTINE.md` for the exact prompt the routine executes.

## Repo layout

| Path                     | Purpose                                                    |
|--------------------------|------------------------------------------------------------|
| `index.html`             | Latest digest, served by GitHub Pages                      |
| `digest-YYYY-MM-DD.html` | Weekly archive snapshots                                   |
| `state.json`             | Last-seen entry id per source (drives the only-new diff)   |
| `templates/digest.html`  | The HTML template the renderer fills                       |
| `src/`                   | Vanilla Bun TS — no installed dependencies                 |
| `ROUTINE.md`             | The prompt the scheduled Claude session runs               |
