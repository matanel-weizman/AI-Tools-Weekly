Sub-agents can spawn their own sub-agents (up to 5 levels deep)

v2.1.172 · Jun 10

Sub-agents may now dispatch their own sub-agents, nesting up to 5 levels. The same release fixes WebFetch(domain:*.example.com) wildcard rules never matching subdomains, and stuck 1M-context sessions now auto-compact back under the standard limit instead of hanging.

Deeper agent trees let an orchestrator decompose work recursively instead of flattening everything into one fan-out — but each level multiplies token spend, so cap depth deliberately.

New --safe-mode, /cd, and disableBundledSkills

v2.1.169 · Jun 8

--safe-mode (and CLAUDE_CODE_SAFE_MODE) starts Claude Code with every customization — CLAUDE.md, plugins, skills, hooks, MCP servers — disabled for troubleshooting. /cd moves a session to a new working directory without breaking the prompt cache. A disableBundledSkills setting hides built-in skills, workflows, and slash commands from the model, and self-hosted runners gain a post-session lifecycle hook.

--safe-mode is the fastest way to prove whether your own config is causing a bug, and disableBundledSkills trims the model's tool surface in locked-down setups.
bashclaude --safe-mode   # start with CLAUDE.md, plugins, skills, hooks, MCP all off

availableModels allowlist is now strictly enforced

v2.1.176 · Jun 12

Two releases tighten model allowlisting. 2.1.175 adds the enforceAvailableModels managed setting: when on, the allowlist also constrains the Default model, and user or project settings can no longer widen a managed list. 2.1.176 stops alias picks from being redirected to a blocked model via ANTHROPIC_DEFAULT_*_MODEL, and /fast now refuses to toggle if it would switch to a model outside the allowlist. The same release also generates session titles in your conversation's language and adds a footerLinksRegexes setting for regex-matched footer link badges.

If your org pins models via availableModels, the env-var and /fast escape hatches are now closed — verify your allowlist still includes every model your team actually needs.

Per-plugin skipMcpDiscovery option

v0.3.172 · Jun 10

The SDK plugins option now accepts skipMcpDiscovery: true per plugin, so a host that manages a plugin's MCP connections itself can load that plugin's skills and hooks without the engine re-reading its .mcp.json. Also fixed slash-then-whitespace input (e.g. / add tests) being silently dropped instead of treated as a plain prompt.

Hosts that own their MCP wiring can adopt plugins for skills and hooks without double-connecting MCP servers.
tsquery({
  options: {
    plugins: [{ path: "./my-plugin", skipMcpDiscovery: true }],
  },
});

Practical ideas — 5 ideas this week

Concrete ways to use this week's changes in your Node / TypeScript service · each tied to a changelog item above
1

Audit your model allowlist before upgrading

v2.1.176 · Jun 12

If your team pins models with a managed availableModels list, the env-var and /fast escape hatches are now closed. Before rolling out 2.1.175+, confirm the allowlist contains every model your developers actually use, including whatever the Default resolves to.

A too-narrow allowlist will now hard-block developers instead of silently falling back to an allowed model.
json// managed-settings.json
{
  "enforceAvailableModels": true,
  "availableModels": ["claude-opus-4-8", "claude-sonnet-4-6"]
}

Cap nesting depth and token budget in recursive agent trees

v2.1.172 · Jun 10

With sub-agents now able to spawn sub-agents up to 5 deep, a recursive orchestrator can blow past your token budget fast. If your service drives Claude Code agents, set an explicit budget and prefer pipelining over deep nesting unless a task genuinely needs it.

Each nesting level multiplies fan-out; an unbounded tree is the easiest way to 10x a run's cost.
claude-code · v2.1.172 · Jun 10 — nested sub-agents
3

Log every model fallback in SDK-based agents

v0.3.174 · Jun 12

If your Node or TypeScript service embeds the Agent SDK, subscribe to system/model_fallback and record the trigger (now including overloaded, server_error, and last_resort). Surface degraded runs in your own metrics rather than letting silent model swaps skew your results.

Knowing when and why you were downgraded is the difference between a debuggable incident and a mystery quality dip.
tsfor await (const msg of query({ prompt })) {
  if (msg.type === "system" && msg.subtype === "model_fallback") {
    metrics.increment("llm.fallback", { trigger: msg.trigger });
  }
}
Claude Agent SDK · v0.3.174 · Jun 12 — model_fallback message
4

Reach for --safe-mode first when a session misbehaves

v2.1.169 · Jun 8

When Claude Code behaves oddly, restart with --safe-mode to disable all customizations (CLAUDE.md, plugins, skills, hooks, MCP). If the problem disappears, the cause is your config — re-enable pieces until it returns.

Bisecting config with a single flag is far faster than guessing which hook or MCP server broke.
bashclaude --safe-mode
claude-code · v2.1.169 · Jun 8 — safe-mode
5

Keep MCP tool input schemas expressive but shallow

v0.139.0 · Jun 9

Codex 0.139 now preserves oneOf/allOf in tool and connector schemas. If you author MCP servers, you can use union and intersection types for tool inputs and expect richer clients to honor them — but keep the schemas shallow so schema compaction on large tool sets stays lossless.

Expressive-but-shallow schemas give the model a precise input contract without being truncated when a client compacts many tools.
