claude --permission-mode manual ...

Validate permissionMode config strings against the known set

break · Jul 18

v0.3.214 rejects unknown permissionMode values instead of ignoring them. If you build that string from user or file config, validate it against the known set at your own boundary so you fail with a clear message rather than a stack trace at startup.

It turns a silent no-op that used to mask typos into a loud failure — catch it where you have context, not where the SDK does.
tsconst MODES = ['manual','acceptEdits','plan','auto'] as const;
if (!MODES.includes(mode as any)) {
  throw new Error(`unknown permissionMode: ${mode}`);
}

Stream large file uploads to OpenAI instead of buffering them

feat · Jul 14

v6.47.0 supports streaming file uploads. For any Node service that forwards user files to OpenAI, pipe a read stream straight through instead of reading the whole file into a Buffer first.

Buffering large files in memory is a top cause of OOM crashes in upload endpoints; streaming keeps memory flat regardless of file size.
tsimport fs from 'node:fs';
await client.files.create({
  file: fs.createReadStream('./big.pdf'),
  purpose: 'assistants',
});
